# WORKFOLIO

Workfolio is a controlled visual portfolio creation studio for software developers, product designers, and digital creative directors.

## Core Capabilities
- **Curated Template Exhibition**: Browse and live-preview 3 distinct portfolio templates (`Noir Collage`, `Atelier Index`, `Monolith Grid`) with Desktop, Tablet, and Mobile views.
- **Controlled Visual Studio**: Edit portfolio sections, reorder or toggle section visibility, swap section layout variants using live-content previews, and edit key headlines and copy inline on the canvas.
- **Project Library & Case Studies**: Add, edit, reorder (via drag-and-drop), feature, and delete case studies with client-side image optimization and interactive focal point picking.
- **Template-Independent Content**: Switch templates, typography pairings, color palettes, and layout density without losing portfolio content, projects, or uploaded imagery.
- **Local-First Persistence**: All portfolios and optimized image assets persist locally in IndexedDB via Dexie.
- **Static Website Export**: Generate and download a standalone `.zip` bundle (`index.html`, `styles.css`, `script.js`, `assets/*`, and `README.txt`) via JSZip.
